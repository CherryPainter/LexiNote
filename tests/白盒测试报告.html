2.2 白盒测试关键技术点

  • 单例绕过构造：DatabaseManager / SettingsManager / AIManager 为单例，测试通过 __new__ 绕过 __init__ 并手动注入依赖（临时目录 / mock），每个用例前后由 conftest 的 autouse fixture 重置 _instance / _initialized，避免状态串扰。
  • 内存 SQLite 集成测试（建议2）：test_database_manager.py 绕过 __init__ 建立临时 SQLite 单例，并强制 execute_write(immediate=True) 立即落库，使「写后读」断言可读到数据，覆盖单词 CRUD、熟练度、学习进度、词库、设置、AI 缓存。
  • 模块层 patch 桩（建议2）：对 cloze_test / reading_comprehension 注入 ComprehensionDatabase / AIService 桩，验证在线生成、离线加载规范化、提交评估、计分、统计、删除全链路。
  • Headless tkinter 共享根：conftest 提供会话级单一 tk_root，规避同一进程内「销毁首个 Tk() 后再建第二个」触发的 TclError。
  • 边界与异常路径：参数化覆盖 URL 归一化、节流下限保护（set_throttle_limits 100ms / 1 次）、JSON 字段缺失 / 拼写容错、流式 content:null 健壮性、AI 不可用降级、除零保护、熟练度区间边界等。

中等 modules/exam_specs.py 未知学段在 prompt 文本显示「未知」
现象
传入不在大纲中的学段（拼写错误）时，命题提示词里学段位置显示字面量「未知」，而非回退默认「高中」。
根因
build_cloze_prompt / build_reading_prompt 的 f-string 直接用 {level}，未对未知 level 回退。
修复
新增 level_name = level if level in CLOZE_SPECS/READING_SPECS else "高中"，f-string 改用 {level_name}（共 4 处）。
验证
py_compile 通过；白盒用例 test_未知阶段回退 断言提示词含「高中」。
中等 modules/ai_service.py 使用陈旧实例属性判断 AI 可用性
现象
generate_reading_comprehension 用 if not self.ai_available:（初始化时缓存快照）判断可用性，运行时切换 ai_mode 后不刷新。
根因
self.ai_available 是初始化快照；应使用实时 property is_ai_available()（覆盖云端 + 本地）。
修复
改为 if not self.is_ai_available():。
验证
py_compile 通过；白盒用例覆盖「云端已配置 → 仍判可用」路径。

中等 已修复 ui/translation_page.py —— 默认 font_config 缺 'header' / 'button' 键
现象
TranslationPage.__init__ 的默认 font_config 仅含 title / normal / small，但代码多处用到 'header'（L63 / L116）与 'button'（L185 起 5 处）；若调用方未传完整 font_config，访问这两个键会抛 KeyError。
