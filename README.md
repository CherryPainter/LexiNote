# LexiNote - 个人英语学习工具

一款基于AI和权重算法的智能英语学习助手，帮助用户高效记忆单词、练习翻译和听写。

## 功能特点

### ✨ 最新功能
- **AI翻译判断**：利用Ollama API智能判断翻译正确性，提供参考翻译
- **学习模式**：主动学习和记忆单词，支持批量学习和掌握度标记
- **单词发音播放**：支持听单词发音，提高听力记忆
- **掌握度跟踪**：智能记录单词掌握情况，调整学习权重
- **键盘快捷键**：支持键盘操作，提高学习效率
- **超时单词权重调整**：听写中超时的单词会被视为未掌握，自动增加其复习权重
- **精确队列控制**：确保设置的听写单词数量准确执行，提升学习计划的可控性

### 🎯 核心功能
- **听写练习**: 播放单词发音，用户输入拼写
- **翻译练习**: 支持英译中和中译英双向翻译
- **单词复习**: 按错误率和权重智能排序复习
- **学习统计**: 记录学习进度和正确率
- **智能算法**: 基于权重的单词调度，错词优先复习

### 🔍 特色功能
- **AI辅助学习**: 集成Ollama API，提供智能翻译判断和参考翻译
- **权重记忆算法**: 错误单词权重增加，正确单词权重降低
- **发音播放**: 自动播放单词发音（需要网络连接）
- **模糊匹配**: 翻译练习支持智能模糊匹配
- **重点标记**: 可手动标记重点单词优先复习
- **每日衰减**: 模拟遗忘曲线，自动调整单词权重
- **双向翻译**: 同时支持英译中和中译英的AI判断
- **备用机制**: 当AI服务不可用时，系统自动回退到原有匹配逻辑

## 安装说明

### 环境要求
- Python 3.12 或更高版本
- Ollama服务（用于AI功能）

### 1. 克隆仓库

```bash
git clone https://github.com/CherryPainter/LexiNote.git
cd LexiNote
```

### 2. 安装依赖

```bash
pip install -r requirements.txt
```

### 3. 配置Ollama
- 下载并安装 [Ollama](https://ollama.com/download)
- 拉取所需模型：`ollama pull qwen2.5:7b-instruct`
- 确保Ollama服务在默认端口(11434)运行

### 4. 运行程序

```bash
python main.py
```

## 使用方法

### 学习模式使用指南

1. 从左侧导航菜单选择"📚 单词学习"
2. 设置批次大小（默认为10个单词）
3. 点击"开始学习"按钮
4. 在单词卡片界面，您可以：
   - 点击"🔊 播放发音"按钮听取单词发音（或按回车键）
   - 点击"需复习"按钮标记单词需要再次复习（或按左方向键）
   - 点击"已掌握"按钮标记单词已掌握（或按右方向键）
5. 完成批次学习后，系统会自动保存学习进度并显示学习统计

### 翻译练习使用指南

1. 从左侧导航菜单选择"🌐 翻译练习"
2. 选择翻译方向（英译中/中译英）
3. 根据显示的单词输入对应的翻译
4. 点击"检查"按钮或按回车键验证答案
5. 系统会使用AI判断翻译的正确性并显示参考翻译
6. 点击"下一步"继续练习

### 听写练习使用指南

1. 从左侧导航菜单选择"🔊 听写练习"
2. 点击「播放发音」按钮听取单词
3. 在输入框中输入单词（系统会设置单词倒计时）
4. 点击「检查」按钮验证答案或按回车键
5. 系统会自动记录错误并调整复习优先级
6. **超时处理**：未能及时回答的单词会被视为未掌握，自动增加复习权重
7. **队列控制**：设置的单词数量会被精确执行，确保您的学习计划可控

### 单词复习使用指南

1. 从左侧导航菜单选择"📝 单词复习"
2. 可选择查看全部单词、错误单词或重点单词
3. 点击「显示翻译」查看单词释义
4. 点击「标记重点」增加单词复习权重

### 掌握度算法说明

- 标记为"已掌握"：掌握度分数 +0.25，权重降低（×0.8）
- 标记为"需复习"：掌握度分数 -0.1，权重增加（+0.3）
- 每日衰减：系统会自动对所有单词权重进行轻微衰减（×0.98），模拟自然遗忘过程

### 快捷键说明

| 操作 | 快捷键 |
|------|--------|
| 播放发音 | 回车键 |
| 标记为需复习 | 左方向键 |
| 标记为已掌握 | 右方向键 |
| 检查答案 | 回车键 |

## 技术原理

### 权重算法
- 初始权重：每个单词初始权重为1.0
- 错误惩罚：每次错误，权重增加0.5
- 正确奖励：每次正确，权重乘以0.8
- 每日衰减：模拟遗忘，所有单词权重轻微增加

这种算法确保了用户总是优先复习那些容易出错的单词，形成高效的学习循环。

### AI翻译判断

从v1.3.2版本开始，翻译判断功能完全交由AI处理：

1. **AI优先判断**：系统默认使用AI来判断翻译的正确性，提供更准确、更智能的判断结果
2. **双向支持**：同时支持英译中和中译英的AI判断
3. **备用机制**：当AI服务不可用时，系统会自动回退到原有的匹配逻辑
4. **视觉反馈**：判断结果会通过醒目的颜色和背景闪烁提供清晰的视觉提示
5. **AI参考翻译**：无论翻译是否正确，都提供AI的参考翻译，帮助用户更好地学习
6. **状态显示**：在状态栏显示当前的判断方式（AI或系统），保持透明度

## 开发说明

### 环境要求
- Python 3.12+
- tkinter (Python标准库)
- requests (用于Ollama API调用)
- gTTS (用于文本转语音)
- playsound (用于音频播放)

### 开发规范
- 遵循PEP8代码规范
- 模块化设计，每个文件负责单一功能
- 所有数据统一保存在data/目录下
- 重要操作记录日志
- UI和逻辑层分离，不允许在UI文件中直接调用AI逻辑
