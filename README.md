# LexiNote - 个人英语学习工具

一款基于权重算法的智能英语学习助手，帮助用户高效记忆单词。

## 功能特点

### ✨ 最新功能
- **学习模式**：主动学习和记忆单词，支持批量学习和掌握度标记
- **单词发音播放**：支持听单词发音，提高听力记忆
- **掌握度跟踪**：智能记录单词掌握情况，调整学习权重
- **键盘快捷键**：支持键盘操作，提高学习效率

### 🎯 核心功能
- **听写练习**: 播放单词发音，用户输入拼写
- **翻译练习**: 支持英译中和中译英双向翻译
- **单词复习**: 按错误率和权重智能排序复习
- **学习统计**: 记录学习进度和正确率
- **智能算法**: 基于权重的单词调度，错词优先复习

### 🔍 特色功能
- **权重记忆算法**: 错误单词权重增加，正确单词权重降低
- **发音播放**: 自动播放单词发音（需要网络连接）
- **模糊匹配**: 翻译练习支持智能模糊匹配
- **重点标记**: 可手动标记重点单词优先复习
- **每日衰减**: 模拟遗忘曲线，自动调整单词权重

## 使用方法

### 学习模式使用指南

1. 从左侧导航菜单选择"📚 单词学习"
2. 设置批次大小（默认为10个单词）
3. 点击"开始学习"按钮
4. 在单词卡片界面，您可以：
   - 点击"🔊 播放发音"按钮听取单词发音（或按回车键）
   - 点击"需复习"按钮标记单词需要再次复习（或按左方向键）
   - 点击"已掌握"按钮标记单词已掌握（或按右方向键）
5. 完成批次学习后，系统会自动保存学习进度并显示学习统计

### 掌握度算法说明

- 标记为"已掌握"：掌握度分数 +0.25，权重降低（×0.8）
- 标记为"需复习"：掌握度分数 -0.1，权重增加（+0.3）
- 每日衰减：系统会自动对所有单词权重进行轻微衰减（×0.98），模拟自然遗忘过程

### 快捷键说明

| 操作 | 快捷键 |
|------|--------|
| 播放发音 | 回车键 |
| 标记为需复习 | 左方向键 |
| 标记为已掌握 | 右方向键 |

### 1. 听写练习
- 点击「播放发音」按钮听取单词
- 在输入框中输入单词
- 点击「检查」按钮验证答案
- 系统会自动记录错误并调整复习优先级

### 2. 翻译练习
- 选择翻译方向（英译中/中译英）
- 输入对应的翻译
- 系统支持模糊匹配，部分正确也能识别

### 3. 单词复习
- 可选择查看全部单词、错误单词或重点单词
- 点击「显示翻译」查看单词释义
- 点击「标记重点」增加单词复习权重

### 4. 学习统计
- 查看总学习单词数、正确率等统计信息
- 了解学习进度和效果

## 技术原理

### 权重算法
- 初始权重：每个单词初始权重为1.0
- 错误惩罚：每次错误，权重增加0.5
- 正确奖励：每次正确，权重乘以0.8
- 每日衰减：模拟遗忘，所有单词权重轻微增加

这种算法确保了用户总是优先复习那些容易出错的单词，形成高效的学习循环。
